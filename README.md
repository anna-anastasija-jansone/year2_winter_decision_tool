# Year 2 Winter Decision Tool

A small browser-only JavaScript application for comparing two possible Year 2 Winter strategies for Pork and Garlic Ice Cream Co.

The starting values are based on the recorded Year 1 Winter position and are labelled as provisional. Update them after each remaining Year 1 season and replace Year 2 estimates once the trainer supplies confirmed rules.

## Run locally

Open `index.html` in a browser, or serve this folder with a simple local web server.

## Publish on Vercel

Import this repository into Vercel. It is a static site and needs no build command or framework preset.
